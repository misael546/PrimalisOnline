# Primalis Online

**Primalis Online** is an independent, mobile-first 3D dinosaur survival game project. The goal is to build a playable prototype using free tools, then evaluate the path to Android and Google Play.

## Current direction
- Third-person 3D survival in a prehistoric environment.
- A controllable starter placeholder character.
- Health, hunger, thirst, and stamina systems planned.
- Touch-first Android controls, with keyboard support for development.
- Architecture planned with future multiplayer in mind; multiplayer is not implemented yet.
- Keep development free and avoid paid APIs/services.

## Development approach
The repository starts with a small Godot 4 prototype and design/rules documents. Prioritize a stable, lightweight vertical slice before expanding the world or adding networking. Use original or properly licensed assets only.

## Project status
Early foundation / prototype. Features described as planned are not necessarily implemented yet.

## Open in Godot
1. Install Godot 4 on a supported computer or compatible Android workflow.
2. Download or clone this repository.
3. Import the folder containing `project.godot`.
4. Run the main scene.

Mobile editing and Android export depend on the device and available tooling. Validate Android export on a compatible setup before promising a Play Store release.
